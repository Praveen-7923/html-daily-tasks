# Day 3 HTML Task 3 – SBI Online NEFT Transfer

## 📌 Project Overview

This project is a simple **SBI Online NEFT Transfer** webpage created using **HTML and CSS**.

The webpage represents an online banking fund-transfer interface where users can:

* Select a bank account
* View account details
* Enter an account number
* Select the purpose of transfer
* Select an intra-bank beneficiary
* Choose a payment option
* Submit or cancel the transaction

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## ✨ Features

### 1. Account Selection

Users can select their account and view:

* Account Number
* Account Type
* Branch
* Account Balance

### 2. Account Details

The page provides an input field to enter the account number and a dropdown menu to select the transfer purpose.

### 3. Beneficiary Selection

Users can select an intra-bank beneficiary from the available beneficiary accounts.

The table displays:

* Account Number
* Beneficiary Name
* Branch
* Transfer Limit

### 4. Payment Options

Users can choose between:

* Pay Now
* Schedule Later

### 5. Banking Notice

A warning message is displayed to remind users that the beneficiary account number must be entered correctly for electronic fund transfer.

### 6. Action Buttons

The page contains:

* **Submit**
* **Cancel**

## 🎨 CSS Features Used

The webpage uses internal CSS for:

* Background color
* Text colors
* Padding
* Button styling
* Heading styling
* Basic page alignment

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `day_3_html_task_3` folder.
3. Open `task2.html` in any web browser.
4. The SBI Online NEFT Transfer webpage will be displayed.
