# School Championship Registration Form

A simple **School Championship Registration Form** created using HTML5 and basic CSS as part of my **Day 2 HTML Task 2**.

## 📌 Project Overview

This project is a registration form designed for students participating in a school championship. It demonstrates the use of different HTML form elements and basic CSS styling.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- School name input
- Student name input
- Password input
- Phone number input
- Email input
- Preferred sport dropdown
- Gender selection using radio buttons
- Parent permission checkbox
- Date selection
- Time selection
- Passport photo upload
- Basic form styling
- Custom colors and button styling
